# Statuts et permissions

## Statuts de documentation des routes

- `legacy` : conservée pour compatibilité ;
- `hors MVP` : disponible mais hors périmètre MVP ;
- `expérimental` : contrat susceptible d'évoluer ;
- `prévu` : cible future, non disponible ;
- `déprécié` : migration requise.

## Permissions Support

| Action | Scope |
| --- | --- |
| Lire le contexte paiement | `diddipay:support-context:read` |
| Demander un remboursement | `diddipay:support-actions:refund-request` |
